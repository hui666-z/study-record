{# ===== Flask Flash消息模板固定写法 ===== with 语句：创建局部作用域，messages变量只在with内部生效 get_flashed_messages(with_categories=true) → 同时获取【消息分类】和【消息文本】 如果不写true，只能拿到纯文本消息，无法区分成功/错误样式 #} {% with messages = get_flashed_messages(with_categories=true) %} {# 判断是否存在flash消息 #} {% if messages %} {# 循环每一条消息：category样式类别，message提示文字 #} {% for category, message in messages %} {# alert-{{category}} 动态样式类： alert-success 绿色成功 alert-danger 红色错误 alert-warning 黄色警告 alert-info 蓝色提示 alert-dismissible fade show：支持关闭动画 #}
{{ message }} {# Bootstrap5关闭按钮，data-bs-dismiss="alert" 点击关闭提示框 #}
{% endfor %} {% endif %} {% endwith %}
